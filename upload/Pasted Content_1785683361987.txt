## 1. OVERVIEW & PRODUCT VISION
────────────────────────────────────────────────────────────
Neon 2048 is the classic 2048 puzzle reborn as a "Neon Arcade" — a
Progressive Web App that installs like a native game, runs full-screen,
and plays forever without a connection after the very first visit.

The product stands on three words:
  • ALIVE   — every surface moves, glows, and responds; nothing on
              screen is dead.
  • FLUID   — zero perceptible jank, even on mid-range phones; input
              feels instant.
  • YOURS   — it installs, it works offline, it never loses progress,
              and it speaks two languages (EN/FA) in two themes
              (dark/light).

────────────────────────────────────────────────────────────
## 2. GOALS & NON-GOALS
────────────────────────────────────────────────────────────
GOALS
  G1  A complete, correct 2048 across five board sizes (2×2 to 6×6).
  G2  A genuinely "real app" experience: native browser install dialog,
      full-screen launch, custom icon, 100% offline play.
  G3  Full preservation of the existing look and functionality
      (improve — never redesign).
  G4  Total elimination of lag and micro-stutter, mobile first.
  G5  Deep motivation: score, per-board bests, combos, heat, ranks,
      15 achievements, Hall of Fame.
  G6  Install + offline education at first contact (onboarding).
  G7  Personalization: dark/light/auto theme + EN/FA with full RTL.
  G8  Flawless GitHub Pages release with the source link on the
      main page.

NON-GOALS (explicitly out of scope)
  • Multiplayer, accounts, servers, cloud saves, in-app purchases.
  • Push notifications, analytics, tracking, any data collection.
  • Gamepad support; a third language (architecture ready, not shipped).
  • On-screen directional controls (fully removed — explicit product
    directive).
  • Page scrolling anywhere (explicit product directive).

────────────────────────────────────────────────────────────
## 3. TARGET USERS & USAGE SCENARIOS
────────────────────────────────────────────────────────────
PRIMARY PERSONA — "the everyday mobile player":
  In a queue, on the metro, while waiting. Mid-range phone. Unstable or
  zero connectivity. No patience for an app-store install. Expects every
  swipe to answer instantly and every sudden close to cost nothing.

KEY SCENARIOS
  S1  First visit → 4-step onboarding → install → offline play in
      airplane mode.
  S2  Mid-game tab/app close → return later → "Continue" card with the
      exact board, score, and even the remaining undo.
  S3  Chrome desktop user → install button → the browser's official
      dialog → standalone app.
  S4  iPhone user → animated Share → Add to Home Screen guide → real
      home-screen app.
  S5  Competitive player → chasing per-board bests, Hall of Fame,
      achievements, and ranks from "Spark" to "Infinity".
  S6  Persian-speaking user → fully RTL interface with Persian numerals,
      while the physical board never mirrors.
  S7  Daylight user → the light "Daylight Arcade" theme with identical
      readability.

────────────────────────────────────────────────────────────
## 4. EXPERIENCE PRINCIPLES (PRODUCT LAW)
────────────────────────────────────────────────────────────
  X1  Absolute fluidity: no animation, swipe, or effect may ever stutter
      — not once.
  X2  The screen belongs to the user: no scrollbars, no D-pad, no
      clutter — everything fits the frame exactly.
  X3  Progress is sacred: "close anytime, lose nothing."
  X4  Installation is a journey, not a feature: taught from the first
      moment, never forced, never annoying.
  X5  A full chromatic spectrum, not a single neon accent: every tile
      tier owns its hue; the stage is layered and living.
  X6  Removal is as important as addition: no extra buttons, no busy
      screens.
  X7  Accessibility is default, not optional.

## 5. FUNCTIONAL REQUIREMENTS
────────────────────────────────────────────────────────────
Priorities: P0 = required for release · P1 = must exist, negotiable
only under schedule pressure.

### 5.1 CORE GAMEPLAY (PRD-GL)
  GL-01 [P0] Classic 2048 rules: swipe/key to slide all tiles to the
        edge; equal tiles merge (each tile merges at most once per
        move); after every successful move one new tile spawns in a
        random empty cell (90% "2", 10% "4").
  GL-02 [P0] Correct loss detection: a full board that still has
        possible merges is NOT a loss.
  GL-03 [P0] A failed move (nothing shifts) has zero effects: no spawn,
        no score change, no undo snapshot.

### 5.2 GAME MODES (PRD-MD)
  MD-01 [P0] Five boards, selectable before the game begins:
        ┌───────┬───────────┬────────────┐
        │ Size  │ Mode      │ Win target │
        ├───────┼───────────┼────────────┤
        │ 2×2   │ Blitz     │ 16         │
        │ 3×3   │ Compact   │ 256        │
        │ 4×4   │ Classic   │ 2048       │
        │ 5×5   │ Grand     │ 2048       │
        │ 6×6   │ Mega      │ 2048       │
        └───────┴───────────┴────────────┘
        Win targets are mathematically tuned per board size.
  MD-02 [P0] Size is chosen only on the start screen; it never changes
        mid-run; the goal is always visible in the HUD.
  MD-03 [P0] Default selection: 4×4 Classic (or the user's last choice).
  MD-04 [P0] Mode chips show name, size, goal, and a mini grid glyph;
        the selected chip is distinguished by glow + border weight.

### 5.3 UNDO — STRICTLY ONE STEP (PRD-UN)
  UN-01 [P0] The undo button reverts exactly and only the last move;
        greater depth is impossible under any circumstance.
  UN-02 [P0] After use, the button stays disabled until the next
        successful move.
  UN-03 [P0] Undo is free and unlimited in frequency; no score penalty.
  UN-04 [P0] Undo restores board, score, move count, merge count,
        highest tile, and heat meter exactly.
  UN-05 [P0] Undo is also available on the Game Over screen as a
        "Rescue" that reopens play.
  UN-06 [P0] Achievements are never rolled back by undo; undo usage is
        tracked as a stat.
  UN-07 [P0] Undo availability survives closing and reopening the game
        (travels with the resume).

### 5.4 INPUT & CONTROLS (PRD-IN)
  IN-01 [P0] Mobile: 4-direction swipe on the board (24px threshold,
        dominant axis). A plain tap = no-op.
  IN-02 [P0] Desktop: arrow keys + WASD; holding a key must not
        machine-gun moves.
  IN-03 [P0] Complete, permanent removal of every on-screen directional
        control (D-pad / arrow buttons / direction widgets) across all
        screens — markup, styling, and logic. Swipe and keyboard are
        the only directional inputs.
  IN-04 [P0] Instant feel: rapid consecutive inputs are never dropped
        and never doubled; the next move fires the moment the previous
        animation completes.
  IN-05 [P0] While any overlay is visible (modal, drawer, onboarding),
        board input is fully gated — no phantom moves underneath.
  IN-06 [P1] Multi-touch: only the first finger is honored.

### 5.5 GAMIFICATION (PRD-GM)
  GM-01 [P0] Base score: sum of the values of tiles created by merges
        each move (two 16s → +32).
  GM-02 [P0] Combo: multiple merges in one move → ×2, ×3, … multiplier;
        a pulsing "COMBO ×N" badge in the hottest merged tile's hue
        (visible ≥ 900ms).
  GM-03 [P0] Heat meter: 10 segments; every move containing a merge
        fills one; a merge-less move resets it; a full meter pays a
        bonus (5 × highest tile) + screen flare + "OVERHEAT" toast,
        then drains.
  GM-04 [P0] Final move score = (base × combo multiplier) + heat bonus.
  GM-05 [P0] Best score tracked separately for each of the five board
        sizes; beating it triggers a "NEW BEST" gold-crown flash.
  GM-06 [P0] Rank titles by highest tile:
        Spark → Glow → Flare → Blaze → Nova → Pulsar → Quasar →
        Supernova → Infinity; rank-ups fire a toast + chime.
  GM-07 [P0] 15 permanent achievements, each with a neon toast (glyph +
        name + description, 3.5s, tap → archive) and an archive drawer
        (locked/unlocked states + unlock dates):
        First Spark · Chain Reaction (3+ merges in one move) ·
        Triple Digits (128) · Half Kilowatt (512) · Neon Master (2048) ·
        Beyond Infinity (4096) · Blitz King (win 2×2) ·
        Perfectionist (win 3×3) · Mega Mind (win 6×6) ·
        Speed Demon (win 4×4 in ≤ 200 moves) · Savior (new highest tile
        within 3 moves after an undo) · Purist (win with zero undos) ·
        Marathoner (500 moves) · Full Spectrum (7+ distinct values on
        board at once) · Overheated (trigger a heat bonus).
  GM-08 [P0] Session stats: moves, merges, active play time (mm:ss),
        max combo, undos used, heat bonuses — compact in the HUD,
        full breakdown in end-game modals.
  GM-09 [P0] Local Hall of Fame: top 5 runs per board size (score,
        moves, time, date); qualifying on game end fires a
        "HALL OF FAME — #N" toast.
  GM-10 [P1] Lifetime totals: games played/won, lifetime moves and
        merges, highest tile ever.

### 5.6 WIN, LOSE & ENDLESS (PRD-WL)
  WL-01 [P0] Reaching the goal tile → celebration: neon confetti +
        shockwave + trophy modal with full stats and three buttons:
        [Continue — Endless] [New Game] [Change Mode].
  WL-02 [P0] The win modal appears once per run; endless play is free,
        and higher milestones (4096) still unlock achievements.
  WL-03 [P0] Loss → desaturation sweep + overlay: final score vs best,
        full stats, buttons: [Undo Rescue] (only when a snapshot
        exists), [Try Again], [Change Mode].
  WL-04 [P0] Game over (no rescue) → Hall of Fame + stats recorded,
        then the active run is cleared; the next game starts clean.

### 5.7 SAVE, RESUME & PROGRESS DURABILITY (PRD-SV)
  SV-01 [P0] Autosave after every successful move + when the page is
        hidden/closed. Worst case after any crash: losing only the
        in-flight move — never more.
  SV-02 [P0] Resume: if an unfinished run exists, the start screen
        shows a "Continue" card: mode, board size, score, highest
        tile, play time, mini board preview + [Continue] and
        [Discard & New Game] buttons.
  SV-03 [P0] Continue → the game restores exactly (including the
        remaining undo) + "Progress restored ✓" toast.
  SV-04 [P0] "Discard & New Game" is destructive: two-step inline
        confirmation ("Tap again to confirm", 2s window) — no
        intrusive modal.
  SV-05 [P0] Bests, achievements, Hall of Fame, and settings persist
        independently of any active run and survive "Discard".
  SV-06 [P0] Recorded time = active play time only; an abandoned open
        tab does not inflate it.
  SV-07 [P1] Live multi-tab sync: best/achievement changes in one tab
        refresh the other tab's start screen.
  SV-08 [P0] Corrupt/unknown data → that entry is safely discarded and
        defaults take over; never a crash or visible error.
  SV-09 [P0] Private browsing: the game is fully playable; a single
        info toast: "Private browsing — progress won't persist".
  SV-10 [P0] Full reset: at the bottom of the How to Play drawer,
        "Reset all progress" with two-step confirmation → wipes
        everything.

### 5.8 VISUAL IDENTITY — "NEON ARCADE" (PRD-VS)
  VS-01 [P0] The existing identity (palette, layout, overall feel) is
        preserved; this document enriches it, never replaces it.
  VS-02 [P0] A four-layer living stage: a drifting synthwave
        perspective grid floor, floating glow orbs (cyan/magenta/
        violet/amber), parallax particle dust, and a vignette. Layers
        live at the edges; the board area stays calm.
  VS-03 [P0] Tile spectrum — every value owns a distinct neon identity
        (hue, glow ring, gradient, text color): 2 cyan → 4 mint →
        8 lime → 16 amber → 32 orange → 64 hot-pink → 128 magenta →
        256 violet → 512 blue-violet → 1024 electric blue → 2048
        radiant gold with animated shimmer → 4096+ iridescent spin.
  VS-04 [P0] Board frame: a dark glassy slab with a neon rim whose hue
        follows the highest tile and breathes gently; cells are
        recessed sockets.
  VS-05 [P0] Two-family typography with strong contrast: large heavy
        display numerals and titles (Orbitron), readable small body and
        letter-spaced labels (Space Grotesk). HUD labels: ~10px,
        uppercase, dim; the score value: the largest number on screen.
  VS-06 [P0] Start screen = arcade "attract mode": a living 2048 logo
        whose mini-tiles merge/split in a 6s loop + tagline
        "MERGE · GLOW · ASCEND". Layout: logo, Continue card (when a
        save exists), mode chips, Start button, secondary links,
        Install, GitHub. No generic centered hero banner — the game
        itself is the hero.
  VS-07 [P0] Buttons/chips: neon pills with hover bloom, press-down
        scale, shine sweep; no interactive element is lifeless.
  VS-08 [P0] App icon: a neon tile with gold "2048" digits on deep
        navy — legible under both themes, on any wallpaper, and still
        recognizable at 48px.

### 5.9 DARK / LIGHT THEMES (PRD-TH)
  TH-01 [P0] Three states: Dark (brand default) / Light / Auto
        (follows the OS, live even mid-game).
  TH-02 [P0] The light theme — "Daylight Arcade" — is an independent,
        designed identity, not an inversion: bright cool stage, faint
        blueprint grid, orbs as soft light pools, saturated jewel
        tiles with soft colored shadows, dark ink text.
  TH-03 [P0] Light-theme readability matches dark: all text/background
        pairs meet at least AA; particles and confetti remain fully
        visible (saturated colors instead of additive glow).
  TH-04 [P0] Theme switch: a smooth ~300ms veil transition with no
        jump; no game state resets.
  TH-05 [P0] Theme control in the header: sun/moon icon with a
        rotate-and-fade animation; an "Auto (follow system)" option in
        the settings drawer.
  TH-06 [P0] Browser chrome / status bar harmonize with the active
        theme; on iOS light theme, status-bar legibility is guaranteed
        by a subtle top scrim.
  TH-07 [P0] The choice persists; an installed app applies the correct
        theme before the first frame of a cold launch.

### 5.10 MOTION & EFFECTS — EVERYTHING ALIVE (PRD-MO)
  MO-01 [P0] Tile spawn: elastic overshoot pop + glow flash.
  MO-02 [P0] Slide: ~130ms with a snappy feel + a short light streak
        along the move direction.
  MO-03 [P0] Merge: scale pulse + expanding shockwave ring + particle
        burst in the tile's hue + brightness spike.
  MO-04 [P0] Score: animated count-up + floating "+N" chips rising from
        each merged cell (staggered, fading).
  MO-05 [P0] Big merges (≥128): subtle screen shake + dual-hue rim
        flash.
  MO-06 [P0] Win: 120–160 particle full-spectrum confetti + central
        shockwave + trophy modal after ~600ms.
  MO-07 [P0] Loss: progressive desaturation + staggered tile dim +
        delayed overlay content.
  MO-08 [P0] Screen transitions (start ↔ game, drawers, modals):
        250–350ms with soft easing; input is never blocked beyond
        ~300ms.
  MO-09 [P0] Living ambience: rim breathing (4s), orb drift (40–90s),
        grid floor motion (12s), logo choreography (6s) — all pause
        when the tab is hidden.
  MO-10 [P0] Micro-interactions on every interactive element: hover,
        press, tap ripple, shine sweep; the install pill carries a slow
        attention pulse.
  MO-11 [P0] Undo: a short 180ms fade/scale to the restored state +
        descending blip.
  MO-12 [P0] Full respect for the OS "reduce motion" setting: shake,
        particles, and ambient loops removed; transitions ≤150ms; no
        information lost.
  MO-13 [P0] An effects-quality control (High/Low) + automatic
        reduction on weak devices; low quality trims decoration only —
        gameplay, input, and feedback are never sacrificed.

### 5.11 SOUND & HAPTICS (PRD-SN)
  SN-01 [P0] All sound is synthesized in real time (no audio files):
        slide whoosh, merge pop with pitch rising by tile value, chain
        chime, heat flare, rank-up arpeggio, achievement ding, win
        arpeggio, lose thud, UI tick, undo blip, new-best ding-ding.
  SN-02 [P0] A mute toggle with an animated icon; the choice persists;
        silence never breaks the experience.
  SN-03 [P0] Sound never plays with latency artifacts or unwanted
        clicks; first playback follows the first user interaction.
  SN-04 [P0] Haptic feedback on mobile: merge 10ms, big merge 25ms,
        heat/win/lose multi-pulse patterns, undo 8ms; plain buttons
        get no vibration (avoid tactile noise).

## 6. NON-FUNCTIONAL REQUIREMENTS
────────────────────────────────────────────────────────────
### 6.1 PERFORMANCE (THE FLUID EXPERIENCE)
  NF-01 [P0] Zero perceptible jank: swipe → slide → merge → spawn is
        perfectly fluid on a mid-range phone; test bar: no dropped
        frames across 20 rapid moves under a weak-device simulation
        (4× CPU slowdown).

topmost; scrim taps close modals/drawers (the tour closes via Skip

## 13. GLOSSARY
────────────────────────────────────────────────────────────
  Merge       Two equal tiles combine into one doubled tile
  Combo       Multiple merges in one move, with a score multiplier
  Heat        A 10-segment streak meter of consecutive merging moves
  Rank        The player's spoken title, by highest tile
  Hall        The local top-5 leaderboard per board size
  Undo        Rewind of exactly one move (also as a game-over rescue)
  Endless     Continuing play after the goal tile is reached
  Attract     The start screen with its living logo, arcade-style
  PWA         An installable, offline-capable web application
  RTL         The right-to-left layout of the Persian locale
