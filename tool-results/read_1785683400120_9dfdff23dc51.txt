    19→    19→## 1. OVERVIEW & PRODUCT VISION
    20→    20→────────────────────────────────────────────────────────────
    21→    21→Neon 2048 is the classic 2048 puzzle reborn as a "Neon Arcade" — a
    22→    22→Progressive Web App that installs like a native game, runs full-screen,
    23→    23→and plays forever without a connection after the very first visit.
    24→    24→
    25→    25→The product stands on three words:
    26→    26→  • ALIVE   — every surface moves, glows, and responds; nothing on
    27→    27→              screen is dead.
    28→    28→  • FLUID   — zero perceptible jank, even on mid-range phones; input
    29→    29→              feels instant.
    30→    30→  • YOURS   — it installs, it works offline, it never loses progress,
    31→    31→              and it speaks two languages (EN/FA) in two themes
    32→    32→              (dark/light).
    33→    33→

    35→    35→## 2. GOALS & NON-GOALS
    36→    36→────────────────────────────────────────────────────────────
    37→    37→GOALS
    38→    38→  G1  A complete, correct 2048 across five board sizes (2×2 to 6×6).
    39→    39→  G2  A genuinely "real app" experience: native browser install dialog,
    40→    40→      full-screen launch, custom icon, 100% offline play.
    41→    41→  G3  Full preservation of the existing look and functionality
    42→    42→      (improve — never redesign).
    43→    43→  G4  Total elimination of lag and micro-stutter, mobile first.
    44→    44→  G5  Deep motivation: score, per-board bests, combos, heat, ranks,
    45→    45→      15 achievements, Hall of Fame.
    46→    46→  G6  Install + offline education at first contact (onboarding).
    47→    47→  G7  Personalization: dark/light/auto theme + EN/FA with full RTL.
    48→    48→  G8  Flawless GitHub Pages release with the source link on the
    49→    49→      main page.
    50→    50→
    51→    51→NON-GOALS (explicitly out of scope)
    52→    52→  • Multiplayer, accounts, servers, cloud saves, in-app purchases.
    53→    53→  • Push notifications, analytics, tracking, any data collection.
    54→    54→  • Gamepad support; a third language (architecture ready, not shipped).
    55→    55→  • On-screen directional controls (fully removed — explicit product
    56→    56→    directive).
    57→    57→  • Page scrolling anywhere (explicit product directive).

    60→    60→## 3. TARGET USERS & USAGE SCENARIOS
    61→    61→────────────────────────────────────────────────────────────
    62→    62→PRIMARY PERSONA — "the everyday mobile player":
    63→    63→  In a queue, on the metro, while waiting. Mid-range phone. Unstable or
    64→    64→  zero connectivity. No patience for an app-store install. Expects every
    65→    65→  swipe to answer instantly and every sudden close to cost nothing.
    66→    66→
    67→    67→KEY SCENARIOS
    68→    68→  S1  First visit → 4-step onboarding → install → offline play in
    69→    69→      airplane mode.
    70→    70→  S2  Mid-game tab/app close → return later → "Continue" card with the
    71→    71→      exact board, score, and even the remaining undo.
    72→    72→  S3  Chrome desktop user → install button → the browser's official
    73→    73→      dialog → standalone app.
    74→    74→  S4  iPhone user → animated Share → Add to Home Screen guide → real
    75→    75→      home-screen app.
    76→    76→  S5  Competitive player → chasing per-board bests, Hall of Fame,
    77→    77→      achievements, and ranks from "Spark" to "Infinity".
    78→    78→  S6  Persian-speaking user → fully RTL interface with Persian numerals,
    79→    79→      while the physical board never mirrors.
    80→    80→  S7  Daylight user → the light "Daylight Arcade" theme with identical
    81→    81→      readability.

    84→    84→## 4. EXPERIENCE PRINCIPLES (PRODUCT LAW)
    85→    85→────────────────────────────────────────────────────────────
    86→    86→  X1  Absolute fluidity: no animation, swipe, or effect may ever stutter
    87→    87→      — not once.
    88→    88→  X2  The screen belongs to the user: no scrollbars, no D-pad, no
    89→    89→      clutter — everything fits the frame exactly.
    90→    90→  X3  Progress is sacred: "close anytime, lose nothing."
    91→    91→  X4  Installation is a journey, not a feature: taught from the first
    92→    92→      moment, never forced, never annoying.
    93→    93→  X5  A full chromatic spectrum, not a single neon accent: every tile
    94→    94→      tier owns its hue; the stage is layered and living.
    95→    95→  X6  Removal is as important as addition: no extra buttons, no busy
    96→    96→      screens.
    97→    97→  X7  Accessibility is default, not optional.

   100→   100→## 5. FUNCTIONAL REQUIREMENTS
   101→   101→────────────────────────────────────────────────────────────
   102→   102→Priorities: P0 = required for release · P1 = must exist, negotiable
   103→   103→only under schedule pressure.
   104→   104→
   105→   105→### 5.1 CORE GAMEPLAY (PRD-GL)
   106→   106→  GL-01 [P0] Classic 2048 rules: swipe/key to slide all tiles to the
   107→   107→        edge; equal tiles merge (each tile merges at most once per
   108→   108→        move); after every successful move one new tile spawns in a
   109→   109→        random empty cell (90% "2", 10% "4").
   110→   110→  GL-02 [P0] Correct loss detection: a full board that still has
   111→   111→        possible merges is NOT a loss.
   112→   112→  GL-03 [P0] A failed move (nothing shifts) has zero effects: no spawn,
   113→   113→        no score change, no undo snapshot.
   114→   114→
   115→   115→### 5.2 GAME MODES (PRD-MD)
   116→   116→  MD-01 [P0] Five boards, selectable before the game begins:
   117→   117→        ┌───────┬───────────┬────────────┐
   118→   118→        │ Size  │ Mode      │ Win target │
   119→   119→        ├───────┼───────────┼────────────┤
   120→   120→        │ 2×2   │ Blitz     │ 16         │
   121→   121→        │ 3×3   │ Compact   │ 256        │
   122→   122→        │ 4×4   │ Classic   │ 2048       │
   123→   123→        │ 5×5   │ Grand     │ 2048       │
   124→   124→        │ 6×6   │ Mega      │ 2048       │
   125→   125→        └───────┴───────────┴────────────┘
   126→   126→        Win targets are mathematically tuned per board size.
   127→   127→  MD-02 [P0] Size is chosen only on the start screen; it never changes
   128→   128→        mid-run; the goal is always visible in the HUD.
   129→   129→  MD-03 [P0] Default selection: 4×4 Classic (or the user's last choice).
   130→   130→  MD-04 [P0] Mode chips show name, size, goal, and a mini grid glyph;
   131→   131→        the selected chip is distinguished by glow + border weight.
   132→   132→
   133→   133→### 5.3 UNDO — STRICTLY ONE STEP (PRD-UN)
   134→   134→  UN-01 [P0] The undo button reverts exactly and only the last move;
   135→   135→        greater depth is impossible under any circumstance.
   136→   136→  UN-02 [P0] After use, the button stays disabled until the next
   137→   137→        successful move.
   138→   138→  UN-03 [P0] Undo is free and unlimited in frequency; no score penalty.
   139→   139→  UN-04 [P0] Undo restores board, score, move count, merge count,
   140→   140→        highest tile, and heat meter exactly.
   141→   141→  UN-05 [P0] Undo is also available on the Game Over screen as a
   142→   142→        "Rescue" that reopens play.
   143→   143→  UN-06 [P0] Achievements are never rolled back by undo; undo usage is
   144→   144→        tracked as a stat.
   145→   145→  UN-07 [P0] Undo availability survives closing and reopening the game
   146→   146→        (travels with the resume).
   147→   147→
   148→   148→### 5.4 INPUT & CONTROLS (PRD-IN)
   149→   149→  IN-01 [P0] Mobile: 4-direction swipe on the board (24px threshold,
   150→   150→        dominant axis). A plain tap = no-op.
   151→   151→  IN-02 [P0] Desktop: arrow keys + WASD; holding a key must not
   152→   152→        machine-gun moves.
   153→   153→  IN-03 [P0] Complete, permanent removal of every on-screen directional
   154→   154→        control (D-pad / arrow buttons / direction widgets) across all
   155→   155→        screens — markup, styling, and logic. Swipe and keyboard are
   156→   156→        the only directional inputs.
   157→   157→  IN-04 [P0] Instant feel: rapid consecutive inputs are never dropped
   158→   158→        and never doubled; the next move fires the moment the previous
   159→   159→        animation completes.
   160→   160→  IN-05 [P0] While any overlay is visible (modal, drawer, onboarding),
   161→   161→        board input is fully gated — no phantom moves underneath.
   162→   162→  IN-06 [P1] Multi-touch: only the first finger is honored.
   163→   163→
   164→   164→### 5.5 GAMIFICATION (PRD-GM)
   165→   165→  GM-01 [P0] Base score: sum of the values of tiles created by merges
   166→   166→        each move (two 16s → +32).
   167→   167→  GM-02 [P0] Combo: multiple merges in one move → ×2, ×3, … multiplier;
   168→   168→        a pulsing "COMBO ×N" badge in the hottest merged tile's hue
   169→   169→        (visible ≥ 900ms).
   170→   170→  GM-03 [P0] Heat meter: 10 segments; every move containing a merge
   171→   171→        fills one; a merge-less move resets it; a full meter pays a
   172→   172→        bonus (5 × highest tile) + screen flare + "OVERHEAT" toast,
   173→   173→        then drains.
   174→   174→  GM-04 [P0] Final move score = (base × combo multiplier) + heat bonus.
   175→   175→  GM-05 [P0] Best score tracked separately for each of the five board
   176→   176→        sizes; beating it triggers a "NEW BEST" gold-crown flash.
   177→   177→  GM-06 [P0] Rank titles by highest tile:
   178→   178→        Spark → Glow → Flare → Blaze → Nova → Pulsar → Quasar →
   179→   179→        Supernova → Infinity; rank-ups fire a toast + chime.
   180→   180→  GM-07 [P0] 15 permanent achievements, each with a neon toast (glyph +
   181→   181→        name + description, 3.5s, tap → archive) and an archive drawer
   182→   182→        (locked/unlocked states + unlock dates):
   183→   183→        First Spark · Chain Reaction (3+ merges in one move) ·
   184→   184→        Triple Digits (128) · Half Kilowatt (512) · Neon Master (2048) ·
   185→   185→        Beyond Infinity (4096) · Blitz King (win 2×2) ·
   186→   186→        Perfectionist (win 3×3) · Mega Mind (win 6×6) ·
   187→   187→        Speed Demon (win 4×4 in ≤ 200 moves) · Savior (new highest tile
   188→   188→        within 3 moves after an undo) · Purist (win with zero undos) ·
   189→   189→        Marathoner (500 moves) · Full Spectrum (7+ distinct values on
   190→   190→        board at once) · Overheated (trigger a heat bonus).
   191→   191→  GM-08 [P0] Session stats: moves, merges, active play time (mm:ss),
   192→   192→        max combo, undos used, heat bonuses — compact in the HUD,
   193→   193→        full breakdown in end-game modals.
   194→   194→  GM-09 [P0] Local Hall of Fame: top 5 runs per board size (score,
   195→   195→        moves, time, date); qualifying on game end fires a
   196→   196→        "HALL OF FAME — #N" toast.
   197→   197→  GM-10 [P1] Lifetime totals: games played/won, lifetime moves and
   198→   198→        merges, highest tile ever.
   199→   199→
   200→   200→### 5.6 WIN, LOSE & ENDLESS (PRD-WL)
   201→   201→  WL-01 [P0] Reaching the goal tile → celebration: neon confetti +
   202→   202→        shockwave + trophy modal with full stats and three buttons:
   203→   203→        [Continue — Endless] [New Game] [Change Mode].
   204→   204→  WL-02 [P0] The win modal appears once per run; endless play is free,
   205→   205→        and higher milestones (4096) still unlock achievements.
   206→   206→  WL-03 [P0] Loss → desaturation sweep + overlay: final score vs best,
   207→   207→        full stats, buttons: [Undo Rescue] (only when a snapshot
   208→   208→        exists), [Try Again], [Change Mode].
   209→   209→  WL-04 [P0] Game over (no rescue) → Hall of Fame + stats recorded,
   210→   210→        then the active run is cleared; the next game starts clean.
   211→   211→
   212→   212→### 5.7 SAVE, RESUME & PROGRESS DURABILITY (PRD-SV)
   213→   213→  SV-01 [P0] Autosave after every successful move + when the page is
   214→   214→        hidden/closed. Worst case after any crash: losing only the
   215→   215→        in-flight move — never more.
   216→   216→  SV-02 [P0] Resume: if an unfinished run exists, the start screen
   217→   217→        shows a "Continue" card: mode, board size, score, highest
   218→   218→        tile, play time, mini board preview + [Continue] and
   219→   219→        [Discard & New Game] buttons.
   220→   220→  SV-03 [P0] Continue → the game restores exactly (including the
   221→   221→        remaining undo) + "Progress restored ✓" toast.
   222→   222→  SV-04 [P0] "Discard & New Game" is destructive: two-step inline
   223→   223→        confirmation ("Tap again to confirm", 2s window) — no
   224→   224→        intrusive modal.
   225→   225→  SV-05 [P0] Bests, achievements, Hall of Fame, and settings persist
   226→   226→        independently of any active run and survive "Discard".
   227→   227→  SV-06 [P0] Recorded time = active play time only; an abandoned open
   228→   228→        tab does not inflate it.
   229→   229→  SV-07 [P1] Live multi-tab sync: best/achievement changes in one tab
   230→   230→        refresh the other tab's start screen.
   231→   231→  SV-08 [P0] Corrupt/unknown data → that entry is safely discarded and
   232→   232→        defaults take over; never a crash or visible error.
   233→   233→  SV-09 [P0] Private browsing: the game is fully playable; a single
   234→   234→        info toast: "Private browsing — progress won't persist".
   235→   235→  SV-10 [P0] Full reset: at the bottom of the How to Play drawer,
   236→   236→        "Reset all progress" with two-step confirmation → wipes
   237→   237→        everything.
   238→   238→
